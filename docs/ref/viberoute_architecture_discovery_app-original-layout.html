System Concept & Repo Split

VibeRoute adopts a strict contract-first design. Frontend & Backend are totally decoupled over HTTP OpenAPI specification.

  • Ingest 2,077 North TAT listings
  • Gemini gemini-embedding-001
  • Supabase pgvector search
  • NVIDIA → Gemini Explain pipeline

  • Search UX & History Sidebar
  • Interactive Map & Popups
  • Photo Upload & Fav Toggles
  • Never holds API keys/vector math
