# รีวิว `viberoute_architecture_discovery_app.html`

เดโมที่แก้แล้วให้นำไปเป็น ref ของ React: [ref/viberoute-frontend-ref.html](ref/viberoute-frontend-ref.html)

ไฟล์เดิมใน Downloads ทับด้วยเวอร์ชันนี้แล้ว ห้ามย้อนไปใช้ mock อินทนนท์/ร่องขุ่น

**เวอร์ชันเก่าใช้เป็นโครงจอได้ ห้ามยกไปเป็น frontend จริง**

เป็นเดโมค้นสถาปัตยกรรม (แท็บ App + แท็บ Architecture) ไม่ใช่ mock ที่ตรงสัญญา OpenAPI การ์ดในไฟล์คิดค่าเข้าชมเอง และโชว์ชื่อโมเดลบนจอนักท่องเที่ยว ซึ่งขัดเดโม anti-hallucination

ตารางสั้นอยู่ที่ canvas `html-demo-review` ใน Cursor ด้วย

## สรุป

| เอาไปใช้ | ไม่เอา |
|---|---|
| เลย์เอาต์ 3 คอลัมน์: ประวัติ / แชท+การ์ด / แผนที่ | mock 6 ที่ดัง + ราคาที่คิดเอง |
| Leaflet ปักหมุด | แถบ NVIDIA / 200 OK / 768 dims บนจอหลัก |
| ช่องการ์ด: ปก, ชื่อ, why, ค่าเข้าชม, เวลา, ตรง/ไม่ตรง, อัปโหลด | ฟิลด์ `id` `name` `vibe_tag` `opening_hours` |
| สวิตช์เมืองรอง + กรองจังหวัด | เรียงรูปเอง, อัปโหลดด้วย URL Unsplash |
| แท็บ Architecture → ย้ายไปแผงสำหรับทีมงาน | Tailwind CDN + โทนเขียวมืดแบบแดชบอร์ด AI |

## โครงที่เก็บได้

- ประวัติซ้าย, การ์ดกลาง, แผนที่ขวา, ช่องพิมพ์ล่าง — ตรงสัญญาจอเดียว
- ป้ายค่าเข้าชม confirmed/unknown มีช่องแล้ว แค่ต้องอ่าน `fee.status` + `fee.label`
- ปุ่มตรง/ไม่ตรง และปุ่มเพิ่มรูปมีแล้ว
- แท็บ Architecture + จำลอง fallback ใช้โชว์กรรมการในแผงทีมงาน ไม่เปิดเป็นหน้าแรก

## จุดที่ถ้าไม่แก้ จะเพี้ยนจากระบบ

**ข้อเท็จจริงปลอม (ห้ามขึ้นเดโมจริง)**

- ดอยอินทนนท์ ค่าเข้า 300/50 บาท, วัดร่องขุ่น 100/ฟรี, เรือกว๊านพะเยา 50 บาท — ไม่ได้มาจากคอลัมน์ TAT
- รูป Unsplash ทั้งชุด TAT ไม่มีรูป ปกว่างจนกว่าผู้ใช้อัปโหลด
- ค้นคำอะไรก็ได้การ์ดเดิม 6 ใบ (อินทนนท์ ร่องขุ่น ปาย …) ไม่เรนเดอร์ `places[]`

**จอหลักพูดภาษาเทคนิค**

- `ACTIVE ENGINE: NVIDIA Nemotron-3.5-30B`
- `200 OK • Vector Retrieval Top-12`
- `Gemini Embedding (768 dims)` ที่ footer
- latency 284ms, Dims 768 ในเฮดเดอร์

สัญญาล็อกว่าจอคนทั่วไปมีแค่ **ผู้ช่วยพร้อม / สำรอง / ยังไม่พร้อม** ชื่อโมเดลอยู่ในสำหรับทีมงาน

**ฟิลด์ไม่ตรง API**

| ใน HTML | ที่ต้องใช้ |
|---|---|
| `id` เช่น `tat-n-001` | `att_id` จาก TAT |
| `name`, จังหวัดอังกฤษ | `name_th`, `province` ไทย |
| `opening_hours` สตริงเดียว | `hours.status` + `hours.label` |
| `fee_text` คิดเอง | `fee.label` จาก backend |
| `llm_explanation`, `vibe_tag` | `why` อย่างเดียว ไม่มีแท็กมู้ด |
| `is_secondary` บนการ์ด | นับจากจังหวัด ≠ เชียงใหม่ หรือโชว์ `secondary_count` |
| health `{status: healthy}` | `{ assistant: { level, label, detail } }` |
| feedback `straight` | `{ message_id, att_id, rating: 1 \| -1 }` |

ยังไม่มีบนการ์ดเดโม: `tel`, `limitation`, `district`, `website`, `facebook`, ป้ายเวลา unknown

**พฤติกรรมที่ต้องเปลี่ยน**

- คลิกประวัติแล้วค้นคำเดิมซ้ำ → ต้อง `GET /v1/chats/{id}` แล้ววาดของที่เก็บไว้
- เรียงรูปตาม fav ในเบราว์เซอร์ → ใช้ `images[]` และ `is_cover` ที่ backend ส่ง
- อัปโหลดด้วย URL → multipart `.jpg .png .webp` ≤ 5MB
- จังหวัดฮาร์ดโค้ด 8 ชื่ออังกฤษ ไม่ครบ 17 จังหวัดเหนือ → ดึง `GET /v1/provinces?region=ภาคเหนือ`
- region value `North` → `ภาคเหนือ`
- สวิตช์เมืองรองไม่ยิงค้นใหม่ และป้ายปิดยังไม่ใช่ «เรียงตามความตรงมู้ด»
- แผนที่ปักครบทุกใบ ไม่รองรับ `lat` เป็น null และใช้แผ่น Carto dark ไม่ใช่ OSM ธรรมดา
- ชิปตัวอย่างดันคาเฟ่เชียงใหม่ / วัดดัง → เปลี่ยนเป็นเคสเดโมที่ล็อกไว้ (สโลว์ไลฟ์, ชุมชนไม่ใช่วัดเชียงใหม่, เมืองเก่าอุทัยธานีไม่มีค่าเข้าชม, คุ้มเจ้าบุรีรัตน์ 60 บาท)
- New Vibe ยังโชว์การ์ด 6 ใบปลอม → หน้าเปล่า + คำชวนพิมพ์

**โทน**

แผนล็อกกระดาษ/หมึก เที่ยวเหนือ ไฟล์นี้เป็นแดชบอร์ดมืดเขียวแบบ AI ใช้เป็นโครงไม่ใช้เป็นธีม

## วิธีให้คน frontend ปรับไปลงมือ

1. แตกเลย์เอาต์นี้เป็นคอมโพเนนต์ Vite/React ตามช่องเดิม
2. ลบ mock `MOCK_TAT_NORTH_PLACES` ทั้งก้อน เรนเดอร์จาก `SearchResponse`
3. ย้ายแถบโมเดล / 768 dims / แท็บ Architecture ไปแผงสำหรับทีมงาน
4. ใส่ `tel` + `limitation` + ป้ายชั่วโมง unknown ตาม `docs/frontend-handoff.md`
5. แผนที่อ่านเฉพาะ `map_points[]`
