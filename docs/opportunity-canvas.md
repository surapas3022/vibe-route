# AI Opportunity Canvas 11 ช่อง vs แผน VibeRoute

สถานะ = ในแผนทำ / ทำบางส่วน / ยังไม่ใส่ใน POC  
ยังไม่มีโค้ดในรีโป นี่คือความครอบคลุมของแผน

| ช่อง | Canvas ขอ | สถานะ | หมายเหตุ |
|---|---|---|---|
| 1. User | นักท่องเที่ยวสายประสบการณ์ + ททท./ชุมชน | บางส่วน | ผู้ใช้แชทครบ ไม่มีพอร์ทัลแอดมิน โปรโมตเมืองรองด้วย rerank + รูป |
| 2. Problem | ค้นด้วยความรู้สึก ชุมชนถูกมองข้าม AI มโน | ในแผนทำ | แกนเดโม |
| 3. Current Process | Google keyword → รีวิว → ข้อมูลผิด | ในแผนทำ | สไลด์ before ไม่ใช่หน้าจอ |
| 4. Pain Point | เสียเวลา คลาด hidden gem ข้อมูลไม่ตรง | ในแผนทำ | การ์ดมู้ด + ป้ายข้อมูลไม่ครบ + เบอร์ |
| 5. AI Capability | NLP/LLM + RAG จากฐาน ททท. | ในแผนทำ | Gemini embed + top-k + LLM อธิบาย ข้อเท็จจริงอ่านคอลัมน์ |
| 6. Required Data | DETAIL, HILIGHT, MARKET_LIMITATION, null | บางส่วน | DETAIL หลัก HILIGHT เมื่อมี ตรวจ null ที่ค่าเข้าชม/เวลา โชว์ MARKET_LIMITATION เมื่อมี |
| 7. AI Output | รายการตรง vibe + แผนที่ + Transparency Card | ในแผนทำ | เพิ่มประวัติ ปุ่มตรง/ไม่ตรง รูปผู้ใช้ |
| 8. Human Role | คนเลือกสถานที่ คนโทรตามป้าย | ในแผนทำ | คนโหวตและอัปโหลดรูปด้วย |
| 9. Business Value | ท่องเที่ยวยั่งยืน ททท. น่าเชื่อถือ | ในแผนทำ | สไลด์ ไม่มีแดชบอร์ดรายได้ |
| 10. Risk | Hallucination กันด้วย prompt | ในแผนทำ | เข้มกว่า Canvas: backend ใส่ fee/hours จากคอลัมน์ |
| 11. KPI | Zero hallucination + คลิกเมืองรอง | ยังไม่ใส่ในแอป | ใช้เคสเดโม + `secondary_count` บนผลค้น ไม่สร้างแดชบอร์ด |

ไม่เพิ่มพอร์ทัล ททท. และไม่สร้างแดชบอร์ด KPI ในรอบแข่ง
